# 사전 등록 (결과를 보기 전에 작성, 2026-10-16)

이 파일은 실험을 실행하기 전에 커밋했다. 이후 수정하지 않는다. 결과 해석은 이 기준을 따른다.

## 가설 (반증 가능)

같은 작업을 다시 풀 때, 첫 시도에서 얻은 접근법·오류·해결을 `notes/`에 남기고 두 번째 시도에서 그 기록을 먼저 읽게 하면,
기록 없이 시작할 때보다 두 번째 시도의 **소요 시간이 짧고, 테스트 통과까지 시도 수가 같거나 적다.**
그리고 그 효과는 "notes 파일을 먼저 읽으라는 지시" 자체가 아니라 **기록의 내용**에서 온다.

## 고정

| 항목 | 값 |
|---|---|
| 도구 | Claude Code 2.1.299, headless(`claude -p`), `--output-format stream-json` |
| 모델 | `claude-sonnet-5-5` (기본 effort) |
| 권한 | `--permission-mode acceptEdits`, `Bash(python:*)` 허용, MCP 없음(`--strict-mcp-config`) |
| 자동 메모리 | 끔(`CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`), 조건 B에 경험이 새어 들어가지 않게 |
| 작업 | parse-log, refactor-util, fix-failing (fixture/ 원본을 시도마다 새로 복사) |
| 요청 문장 | `scripts/run_trial.py`의 `TASKS` 문장 그대로. A·C만 끝에 "notes/를 먼저 읽고 참고해" 한 문장 추가 |
| 예산 | 시도당 최대 3회 요청(실패하면 같은 세션 이어서 재요청), 요청당 15분 제한 |
| 세션 | 시도마다 새 세션 (앞 시도의 대화 없음) |

## 조작 (하나: notes/의 내용)

| 조건 | 2차 시도 때 notes/ |
|---|---|
| A 경험 기록 | 1차 시도(A) 직후 같은 세션에서 Claude가 쓴 `notes/<task>.md` (3줄 이내: 접근법, 만난 오류와 근거, 해결) |
| B 대조 | 없음, 추가 문장도 없음 |
| C 위약 | `scripts/placebo_notes/` — 같은 3줄 형식, 작업과 무관한 일반론. 요청 문장은 A와 동일 |

2차 시도는 조건마다 3회 반복한다. 실행 순서는 작업별로 A→B→C를 번갈아 돌린다.

## 측정

- 주 지표: 소요 시간(벽시계 초, 재요청 포함 합계), 테스트 통과까지 시도 수
- 보조 지표: 입력·출력 토큰, 편집 도구 호출 수(Edit/Write), 전체 도구 호출 수, 권한 거부 수(승인 요청이 필요했을 횟수), 비용
- 해결률: 3회 안에 테스트 통과 && 테스트 파일 무변경

## 사전 판정식

작업별로 2차 시도 3회의 **중앙값**을 비교한다.

- 작업 하나에서 "A가 X보다 낫다" = A의 해결률 ≥ X의 해결률 **그리고** A의 시간 중앙값이 X보다 **10% 이상** 짧음 **그리고** A의 시도 수 중앙값 ≤ X
- **가설 지지**: A가 B보다 나은 작업이 3개 중 2개 이상 **그리고** A가 C보다 나은 작업도 2개 이상
- **부분 지지(원인 설명 기각)**: A가 B보다 2개 이상에서 낫지만, C보다는 그렇지 않음 → 효과가 기록 내용이 아니라 "먼저 읽으라는 지시"에서 왔을 수 있음
- **기각**: A가 B보다 나은 작업이 1개 이하

토큰과 편집 횟수는 판정에 쓰지 않고 해석에만 쓴다. 3회 값의 범위(최소~최대)가 겹치면 "차이가 약함"이라고 함께 적는다.
측정값이 없으면 지어내지 않고 "미확인"으로 적는다.
